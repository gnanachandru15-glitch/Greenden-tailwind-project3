# 🌿 Greenden

Greenden is a responsive plant shop website built using **HTML** and **Tailwind CSS**. This project is designed to showcase a modern and clean user interface for an online plant store.

## 🚀 Features

- 🌱 Responsive design for all devices
- 🎨 Modern UI with Tailwind CSS
- 🏡 Attractive homepage
- 🪴 Plant product sections
- 📱 Mobile-friendly navigation
- ⚡ Fast and lightweight

## 🛠️ Built With

- HTML5
- Tailwind CSS

## 📂 Project Structure

```
Greenden/
│── index.html
│── products.html
│── contact.html
│── css/
│── images/
│── README.md
```
